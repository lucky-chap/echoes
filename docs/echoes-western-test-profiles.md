# Three Western profiles for testing Echoes

These are fictional test profiles, not real resident records. Enter each separately. Favourites and avoid topics below are already comma-separated for the app.

After entering the notes, use **Help understand these notes**, review the extracted preferences, and select **I reviewed and confirm these preferences**. You can also enter the suggested preference values below manually. Confirm preferences after your final notes edit so the planner can use them.

These inputs have not been run against the latest regional filters. The checks describe intended behavior, not guaranteed Qloo results.

## Quick checklist for all three

- The plan totals 30 minutes and uses at least two confirmed-note activities or prompts.
- Prompts are distinct, concrete, and easy to decline.
- Discoveries have date and relevance evidence; missing coverage is stated rather than filled with unrelated media.
- Replacement choices fit the same media domain and the person.
- Books, if returned, are conversation topics without a YouTube playback/search button.
- Named favourites outside the discovery window are clearly labelled as exceptions.

If something looks wrong, record the profile, item or prompt, and what you expected. The **Checks** or diagnostic trace can help distinguish an empty provider response from an item held back by date, relevance, or avoid checks.
